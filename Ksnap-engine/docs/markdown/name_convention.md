## Name Convention
**In Ksync we proposed that the snake case would be the main naming standard. Below some more details.**

---
## Quick Overview
| Token  | Example Name |
| ------------- |:-------------:|
| Variables      |main_pid      |
| Typedef      | main_pid_t     |
| Functions   | main_pid()      |


---
## Bracket Style
About brackets we use them in their own line so it enable us to save some line space.

```
    // quick example 
    int get_pid(int process, int* result){
        // some code here
    }
```
