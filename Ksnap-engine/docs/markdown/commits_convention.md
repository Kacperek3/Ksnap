# Commits convention
**To make easier to search your commit history you should strictly obey to the commits naming convention. Below some more details.**

---
## Quick Overview
Inside of () you should include the file you just changed if possible.

| Name syntax | Function |
| ------------- |:-------------:|
| feat() | If you implemented new code with new usages | 
| fix() | If you fixed any errors or bugs | 
| refactor() | If you changed current code without adding new features |
| docs() | If you changed or create new docs (doxygen or markdown etc.) |
| chore() | If you changed or add config file (No src files should be included here! ) |
| test() | If you changed or add test files |
